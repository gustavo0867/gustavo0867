# Olá, sou o Gustavo Ferreira! 👋

**Desenvolvedor Full Stack Júnior | PHP • Laravel • Vue.js • PostgreSQL • Docker**

Sou desenvolvedor de software graduado em **Sistemas de Informação pela UFGD** e com formação técnica em **Informática pelo IFSP**. Atuo no desenvolvimento, sustentação e deploy de aplicações web em produção, incluindo plataformas educacionais utilizadas diariamente por mais de **5 mil usuários reais** em mais de 20 municípios.

---

### 💻 Experiência & Foco Técnico
* **Back-end:** Desenvolvimento de APIs RESTful robustas, modelagem e otimização de banco com **PHP (Laravel, CodeIgniter)** e **PostgreSQL**.
* **Front-end:** Criação de interfaces reativas e dinâmicas com **Vue.js**, **JavaScript (ES6+)** e **Bootstrap**.
* **DevOps & Infraestrutura:** Automação de deploys com **GitLab CI/CD**, orquestração de containers com **Docker/Docker Compose**, servidores web com **Nginx/Apache** e resolução de incidentes em ambiente Linux.
* **Qualidade de Software:** Prática diária de Code Review, refatoração orientada a **Clean Code** e princípios **SOLID**.
